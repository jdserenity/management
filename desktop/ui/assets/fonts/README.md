# Haglos (Daily wordmark)

The Daily tab title uses **Haglos**. It is not on npm; install the OTF into this folder.

**Automatic (needs network):**

```bash
npm run font:haglos
```

(`build` / `build:companion` run this automatically. Prefer dafont; 1001fonts often blocks bots.)

**Manual:** download from [dafont — Haglos](https://www.dafont.com/haglos.font) or [1001fonts — Haglos](https://www.1001fonts.com/haglos-font.html), unzip, and save the regular OTF as `Haglos-Regular.otf` in this directory. The OTF is gitignored (no redistribute).

See `HAGLOS-LICENSE.txt` for licensing (personal use vs commercial).

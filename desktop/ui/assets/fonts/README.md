# Haglos (Daily wordmark)

The Daily tab title uses **Haglos**. It is not on npm; install the OTF into this folder.

**Automatic (needs network):**

```bash
npm run font:haglos
```

**Manual:** download from [1001fonts — Haglos](https://www.1001fonts.com/haglos-font.html), unzip, and save the regular OTF as `Haglos-Regular.otf` in this directory.

See `HAGLOS-LICENSE.txt` for licensing (personal use vs commercial).
